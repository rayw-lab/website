## W1 锚点量化门（从 `anchor-inkwash-tests.png` 逐项读出，非凭印象）

| # | 指标 | 下限判据 | 为什么它是"像水墨"的开关 |
|---|---|---|---|
| **A1** | **边缘沉积** | 墨块边界内 1–3px 的密度 ≥ 中心密度 × **1.15** | 锚点图第一排灰墨块的边缘明显深于中心；这一处不做足，出图立刻像"高斯模糊的灰斑" |
| **A2** | **洇边分形度** | 墨迹轮廓 周长²/面积 ≥ **4π × 1.3**（圆 = 4π） | 锚点图的洇是云朵状 lobes 不是圆；圆边 = 一眼假 |
| **A3** | **纸噪声幅度** | 空白纸区亮度标准差 ∈ **[0.008, 0.025]** | 锚点纸有可见但极克制的纤维；超上限 = 脏，低于下限 = 塑料感 |
| **A4** | **浓处不死黑** | 最浓处亮度 ≥ **0.06**（非 0） | Beer–Lambert 的价值就在这：密度相加永不糊成死黑 |
| **A5** | **色谱分离** | 外晕色相与核心色相差 ≥ **15°** | 锚点图彩墨周围有异色晕；我们做单色紫墨，靠这一条撑住"墨是活的" |

## W1b 锚点门（`scripts-local-nexus-w1b-gate.mjs`，可复跑）

| 门 | 判据 | 为什么这么定 |
|---|---|---|
| B1 停帧确定性 | 同 URL 连截两次，PNG sha256 相同 | `seek()` 到点 ≠ 停帧：IO 仍启 rAF 时截图内容取决于等待毫秒数 |
| B2 uniform 接通 | `mobhi=5.0`（应让墨几乎冻结）必须改变出图 | 读回值正确 ≠ 管线接通，须用**极端值**定谳 |
| B3 迁移率响应 | `mobhi=0.3` 必须改变出图 | 与 B2 一起排除"参数不敏感"与"传参断了"的混淆 |
| B4 干纸·笔心在内 | 全屏干纸下落笔与不落笔**逐字节相同** | 2×2 唯一变量：同 mask 下只变落不落笔 |
| B5 干纸·笔心在外 | 干区核心最大色阶差 ≤12 | 高斯尾会越过边界；门槛=理论上界 5.4 的 2 倍（推导见下） |
| B5-正控 | 该笔在纸上别处确实画出来了 | 没有正控的负控不闭合——"没变化"要能区分"拦住了"与"根本没落笔" |

**B5 门槛的推导（判据要有物理依据，不能为通过而调）**：核心区边缘 mask=0.972 → gate 尚有 2.8%；
笔的高斯在该处为 0.21；密度 1.7×0.21×0.028=0.010；经 Beer–Lambert 约 5.4 色阶。
实测 7–8，与理论同量级，且相对**未加门时的 230 衰减 29 倍**。
🔴 判据是容差不是逐字节：**真实宣纸的胶矾边界不是刀切，零渗漏反而假**。
