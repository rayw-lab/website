# 多语种座舱大模型 · 成本粗估 使用说明

这个工具估的是讯飞做奇瑞多语种座舱大模型项目的**成本**：一次性开发费 NRE（万元）和随车授权 LIC（元/车/三年）。它不是报价，报价请下载 Excel 后自己调整。

## 一、三步出数

1. **选包和档位**：先选货架或 SOR 包（Carmind3.0 欧盟澳新包、Carmind3.0 东盟包、Carmind1.5 欧盟版、Carmind1.5 俄罗斯版）。Carmind3.0 的两个包还要选档位 MAX / PRO / Lite，档位决定每个智能体是承接、部分承接还是不承接。
2. **填车型**：从下拉里选，或者直接输入一个新车型。判断首发还是横展要看这台车之前交付过什么。
3. **选区域**：可以多选。每个区域自带一份语种名单（都含英语），多个区域的语种会自动去重。

三步选完，中间的货架会列出这个包的全部智能体。**智能体默认一个都不勾**，可以逐个点卡片勾选，也可以用货架上方的「一键勾选」：

- **全选可承接**：勾上当前档位能承接的全部智能体；
- **只看首发**：只勾需要从头建设的；
- **只看沿用我方能力**：只勾能复用我方已有能力的；
- **清空**：全部取消。

## 二、顶栏快捷入口

顶栏右侧四个入口，点一下就带入我们做过的成本项目场景，可以在这个基础上接着改：

| 入口 | 带入的选择 |
| --- | --- |
| EHV 欧盟澳新 | Carmind3.0 欧盟澳新包 · MAX · EHV · 欧盟 + 澳新 · 全选可承接 |
| EHV 东盟 | Carmind3.0 东盟包 · MAX · EHV · 东盟 · 全选可承接 |
| 欧盟二期 | Carmind1.5 欧盟版 · T13C · 欧盟 · 只勾二期五个智能体 |
| 俄罗斯二期 | Carmind1.5 俄罗斯版 · T22FL · 俄罗斯 · 只勾二期智能体 |

## 三、怎么看结果

右侧结果栏从上往下依次是：

- **NRE 总数**：已知部分的合计。如果有还没有单价或底数的项，会显示「待补」按钮，点开能看到缺的是哪几项；待补项不计入合计。
- **成本怎么堆起来的**：按研究院、产研、五职能、语种首发、基础语音语种费、直接费用六段堆出总数。点任意一根柱子，会弹出这一部分的算式和出处。
- **计数**：首发、横展、融合、含待补、不计入各有几个智能体。
- **最贵的三项**：NRE 最高的三个智能体，点开看算式。
- **LIC**：基础语音可以在「在线 / 离线」之间切换；大模型智能体的 LIC 由信源、服务器扩容、token 三类分摊组成。拖动「日活跃率」「每天次数」会改变 token 分摊，「恢复默认」回到总表默认值。
- **两套方案对比**：当前选择可以存为方案 A、方案 B，下面会并排列出差额；含待补的数字会标「+待补」。

每张智能体卡片上的数字也能点开，看这一行的人月、单价和出处。

## 四、改判与微调

- **手改首发 / 横展**：卡片上的「首发」「横展」标签点一下就改判，再点一次撤回。已经交付过的不能改。
- **剔除语种**：语种行里点一下某个语种就把它剔除，再点一次加回来。「折算怎么算？」会解释语种权重。
- **分市场验收**：多个区域分别验收时打开，第一个区域之外每多一个区域，加一份验收人月。
- **系统方切换适配**：换系统方时打开，横展行会加上切换适配的工作量；没有定额的行会注明。
- **撤销**：每一步改动底部都会提示，可以点「撤销」或按 ⌘Z / Ctrl+Z 退回上一步。

## 五、算法口径

- **首发和横展**：某个我方能力在任何车型上都没交付过，就是首发，成本包含研究院投入；交付过的沿用到新车型叫横展，只算项目、产品、开发、测试、技术支持五个职能。首发还是横展只看能力，不看区域。
- **分摊比例**：研究院投入按 1/5 计入奇瑞（五大区，奇瑞算一个），汽车 BU 产研按 0.25 计入，交付五职能不分摊。多个能力共用的一份研究院投入只算一次，由勾选到的能力平分。
- **共用能力只算一次**：两张卡含同一能力、都按首发计时，这个能力只在靠前的那张里算一次，靠后那张整行打折。现在有两处：周边推荐（AI 向导与 AI 生活助理，生活助理 × 0.5，周边推荐与生态服务工作量基本对半）；一期导航（AI 向导与导航&通勤无忧，导航&通勤无忧 × 0.7，导航约占三块能力的三成）。比例在 Excel 的黄格里可以改；任一张按横展计时不扣。
- **语种**：已经交付或验证过的语种在横展里只做回归，按语系折算：锚点语种 1.0，同语系 0.5。没做过的语种另算语种首发：语系里已有交付语种的按 0.5；全新语系里锚点语种按 1.0，其他语种按 0.5。语种首发按语种算一次，不按智能体重复。
- **基础语音语种费**：语种第一次做计一次首发费；已经做过的语种搬到新车型，每台车型计一次搬迁费。
- **LIC**：一律按三年计。基础语音是固定项；大模型智能体按信源、服务器扩容、token 三类分摊。

## 六、保存、分享和下载

- **复制链接**：当前的全部选择会写进链接，发给同事打开就是同一个场景。参数换版后再打开旧链接，会按新参数重算并提示。
- **浏览器记忆**：同一个浏览器再次打开会恢复上次的选择。
- **下载 Excel（带公式）**：下载的 Excel 有三张表：「你选了什么」「NRE 明细」「LIC 明细」。表里是活公式，黄色格子可以改；待补的格子留空，补上数字后这一行和合计会跟着重算。要改成报价，就在这份 Excel 里调整。

## 七、注意

- 页面和 Excel 都是**成本粗估，不是报价**。
- 标「待补」的项还没有单价或底数，不计入合计；合计旁会注明不含哪些项。
- 首发和横展的判断依据目前只有两条交付记录：T13C 欧盟、T22FL 俄罗斯（Carmind1.5 一期）。
- 计算全部在浏览器里完成，不上传任何数据。
