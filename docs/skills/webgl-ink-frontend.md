# 一、视觉物理

1. **要「墨」不要「彩」：落笔密度必须三通道中性。**
   色谱分离只应由扩散速率差（`CHROMA`）在**外缘**生成。把偏色写进初始 density，
   墨核本身就在选择性吸收 → 整滴发紫/发绿，一眼假。
   实证：density `[0.55,0.72,0.42]`（G+31%）叠加 `ABSORB.g=1.12` → 碘酒紫。
2. **墨的冷暖在 ABSORB，不在 density。** 吸红>吸绿>吸蓝 → 残留偏冷 → 冷黑；
   三通道相等 → 死灰。Beer–Lambert `col = paper * exp(-density * absorb)` 下浓处趋黑但永不死黑。
3. **各向异性必须进「迁移率」，不能只进显示层。**
   把纸纤维噪声只放在 display，洇散数学仍是各向同性 → 必然收敛成高斯圆。
4. **纸纤维的空间尺度必须远小于最大笔触**，否则大笔把噪声平均掉、边界重新变圆。
5. **分形边缘 = 多尺度自相似**：单一尺度的湿斑，大笔只是小笔的等比放大，看起来照样平滑。
   必须补一层显著更小、更密的次级湿斑。
6. **相对扰动强度 = kick / radius**，缩放冲量时按线性（∝radius）而非 sqrt，
   否则大笔"更平静"。但冲量总量翻几倍会把颜料整个吹散 —— 且**引擎不报错、`ready` 正常、
   console 全干净，只是画面全白**，是最难查的一类。
7. **形态不好看时先换 seed 再改算法。** 大笔触收敛成圆连查四个假设（纤维频率/次级湿斑/
   kick 缩放/sim 分辨率）各只有微小改善，真因是 seed 恰好接近均匀分布。
   判据：**同一维度连加三个候选都只有微小改善 → 换维度，先怀疑输入而不是模型。**
8. **数值稳定性：所有写速度场的 pass 都要 clamp**，不能只 clamp 涡量那一处。
   R16F 上限 65504，`exp(-inf)=0` 死黑、`-log(0)=NaN`。

# 二、权限/遮罩类语义

9. **遮罩压「状态场」≠ 拦「新输入」。** 湿度遮罩管的是「已有的墨会不会扩散过去」，
   对直接 splat 进来的新笔零拦截。两条路径要分别闭合。
10. **CPU 侧只判笔心是不够的**：splat 是高斯足迹，笔心在边界外侧时尾巴照样写进去。
    安全线必须逐片元；CPU 判定只配当 early-out。
11. **同一个 program 既画遮罩又采样遮罩 = 采样正在写的纹理（UB），gate 会静默失效。**
    修法是**第二个 Program 实例**，不是放弃 GPU 路线。
12. 不要用「每帧 `field *= (1-mask)`」代替落笔拦截：高斯 mask 的无限尾会变成常驻蒸发场。

# 三、探针纪律（本轮 5 次「被测对象有问题」全是探针自己错）

13. **下「被测对象有问题」的结论前，先用一个已知正例证明探针本身是对的。**
14. **对照组逐对只变一个东西。** 干纸门连判三轮 FAIL 全是判据错：
    ①clip 取到 mask 只剩 0.27 的边缘 ②各 case 的 `seek` 时长没对齐
    ③全屏遮罩本身就会冻结已有内容，与"落不落笔"无关。
15. **读回值正确 ≠ 管线接通。** uniform 读回 0.3 而出图逐字节相同 → 用**极端值**定谳
    （给一个必然改变画面的值，仍不变 = 断线）。
16. **脚本化改代码的替换必须带命中断言。** `str.replace` 不匹配时静默返回原文；
    改了 uniform 声明没改使用处 → GLSL 优化掉未使用 uniform → `getUniformLocation`
    返回 null → `uniform1f` 静默无效。
17. **改了源码必须 rebuild**：preview 服务的是 `dist/`。
    且 Astro 把页面 `<script>` 打包成外部 `_astro/*.js`，
    **grep 单个 `index.html` 找新代码标记必然 0 命中**——别据此判定"服务的是旧产物"。
18. `astro preview` 检测到已有实例会 **SKIP 不起新端口**，只打 info 级日志；
    `until curl <新端口>` 会空等到超时。
19. 判据门槛要有**物理/数学推导**，不能为了通过而调。
    例：边界渗漏门槛 12 色阶 = 理论上界 5.4 的 2 倍；真实宣纸胶矾边界不是刀切，
    **零渗漏反而假**，所以判据是容差不是逐字节。

# 四、确定性与截图

20. **`seek()` 到目标时刻 ≠ 停帧**：若 IntersectionObserver 仍启 rAF，
    截图内容取决于等待了多少毫秒。停帧模式必须显式关闭自动循环。
21. **确定性的坐实方式**：同 URL 连截两次，PNG sha256 必须相同。
22. 参数网格/审计栅格的**拍摄时刻必须晚于被审代码的最后一次修改**，
    否则外部审计员会校准到一套已不存在的参数。

# 五、把观测升格成机制之前（2026-09-04 一夜六连错的教训）

23. **一夜之内我下了六个机制性结论，六个全错**：CSS 全角引号致样式丢弃 / `preserveDrawingBuffer`
    是截图必需 / kick≈66 吹散颜料 / vigor 顶进吹散区 / 首次加载不可靠 / build 竞态。
    每一条都曾写进代码注释或台账，每一条都有一个听起来很合理的机理。
24. **合理的机理最危险**——它让人停止追问。真正该问的是：
    **「我这次和上次之间，除了我以为的那个变量，还变了什么？」答不出至少三个候选，
    就说明还没资格下结论。**
25. **复现不出来就说复现不出来。** 现象真实发生过（像素读数为证）不等于你找到了原因；
    22 次受控采样零复现时，正确的结论是「无法复现」，不是「换一个机理再解释一遍」。
26. 无害的保险（预热一次、加上限）可以留，但**注释里只写「保险」，不写机理** ——
    写了机理，下一个人就会把它当已证事实往上叠。
