# 一、视觉物理

1. **要「墨」不要「彩」：落笔密度必须三通道中性。**
   色谱分离只应由扩散速率差（`CHROMA`）在**外缘**生成。把偏色写进初始 density，
   墨核本身就在选择性吸收 → 整滴发紫/发绿，一眼假。
   实证：density `[0.55,0.72,0.42]`（G+31%）叠加 `ABSORB.g=1.12` → 碘酒紫。
2. **墨的冷暖在 ABSORB，不在 density。** 吸红>吸绿>吸蓝 → 残留偏冷 → 冷黑；
   三通道相等 → 死灰。Beer–Lambert `col = paper * exp(-density * absorb)` 下浓处趋黑但永不死黑。
3. **各向异性必须进「迁移率」，不能只进显示层。**
   把纸纤维噪声只放在 display，洇散数学仍是各向同性 → 必然收敛成高斯圆。
4. **纸纤维的空间尺度必须远小于最大笔触**，否则大笔把噪声平均掉、边界重新变圆。
5. **分形边缘 = 多尺度自相似**：单一尺度的湿斑，大笔只是小笔的等比放大，看起来照样平滑。
   必须补一层显著更小、更密的次级湿斑。
6. **相对扰动强度 = kick / radius**，缩放冲量时按线性（∝radius）而非 sqrt，
   否则大笔"更平静"。但冲量总量翻几倍会把颜料整个吹散 —— 且**引擎不报错、`ready` 正常、
   console 全干净，只是画面全白**，是最难查的一类。
7. **形态不好看时先换 seed 再改算法。** 大笔触收敛成圆连查四个假设（纤维频率/次级湿斑/
   kick 缩放/sim 分辨率）各只有微小改善，真因是 seed 恰好接近均匀分布。
   判据：**同一维度连加三个候选都只有微小改善 → 换维度，先怀疑输入而不是模型。**
8. **数值稳定性：所有写速度场的 pass 都要 clamp**，不能只 clamp 涡量那一处。
   R16F 上限 65504，`exp(-inf)=0` 死黑、`-log(0)=NaN`。

# 二、权限/遮罩类语义

9. **遮罩压「状态场」≠ 拦「新输入」。** 湿度遮罩管的是「已有的墨会不会扩散过去」，
   对直接 splat 进来的新笔零拦截。两条路径要分别闭合。
10. **CPU 侧只判笔心是不够的**：splat 是高斯足迹，笔心在边界外侧时尾巴照样写进去。
    安全线必须逐片元；CPU 判定只配当 early-out。
11. **同一个 program 既画遮罩又采样遮罩 = 采样正在写的纹理（UB），gate 会静默失效。**
    修法是**第二个 Program 实例**，不是放弃 GPU 路线。
12. 不要用「每帧 `field *= (1-mask)`」代替落笔拦截：高斯 mask 的无限尾会变成常驻蒸发场。

# 三、探针纪律（本轮 5 次「被测对象有问题」全是探针自己错）

13. **下「被测对象有问题」的结论前，先用一个已知正例证明探针本身是对的。**
14. **对照组逐对只变一个东西。** 干纸门连判三轮 FAIL 全是判据错：
    ①clip 取到 mask 只剩 0.27 的边缘 ②各 case 的 `seek` 时长没对齐
    ③全屏遮罩本身就会冻结已有内容，与"落不落笔"无关。
15. **读回值正确 ≠ 管线接通。** uniform 读回 0.3 而出图逐字节相同 → 用**极端值**定谳
    （给一个必然改变画面的值，仍不变 = 断线）。
16. **脚本化改代码的替换必须带命中断言。** `str.replace` 不匹配时静默返回原文；
    改了 uniform 声明没改使用处 → GLSL 优化掉未使用 uniform → `getUniformLocation`
    返回 null → `uniform1f` 静默无效。
17. **改了源码必须 rebuild**：preview 服务的是 `dist/`。
    且 Astro 把页面 `<script>` 打包成外部 `_astro/*.js`，
    **grep 单个 `index.html` 找新代码标记必然 0 命中**——别据此判定"服务的是旧产物"。
18. `astro preview` 检测到已有实例会 **SKIP 不起新端口**，只打 info 级日志；
    `until curl <新端口>` 会空等到超时。
19. 判据门槛要有**物理/数学推导**，不能为了通过而调。
    例：边界渗漏门槛 12 色阶 = 理论上界 5.4 的 2 倍；真实宣纸胶矾边界不是刀切，
    **零渗漏反而假**，所以判据是容差不是逐字节。

# 四、确定性与截图

20. **`seek()` 到目标时刻 ≠ 停帧**：若 IntersectionObserver 仍启 rAF，
    截图内容取决于等待了多少毫秒。停帧模式必须显式关闭自动循环。
21. **确定性的坐实方式**：同 URL 连截两次，PNG sha256 必须相同。
22. 参数网格/审计栅格的**拍摄时刻必须晚于被审代码的最后一次修改**，
    否则外部审计员会校准到一套已不存在的参数。

# 五、把观测升格成机制之前（2026-09-04 一夜六连错的教训）

23. **一夜之内我下了六个机制性结论，六个全错**：CSS 全角引号致样式丢弃 / `preserveDrawingBuffer`
    是截图必需 / kick≈66 吹散颜料 / vigor 顶进吹散区 / 首次加载不可靠 / build 竞态。
    每一条都曾写进代码注释或台账，每一条都有一个听起来很合理的机理。
24. **合理的机理最危险**——它让人停止追问。真正该问的是：
    **「我这次和上次之间，除了我以为的那个变量，还变了什么？」答不出至少三个候选，
    就说明还没资格下结论。**
25. **复现不出来就说复现不出来。** 现象真实发生过（像素读数为证）不等于你找到了原因；
    22 次受控采样零复现时，正确的结论是「无法复现」，不是「换一个机理再解释一遍」。
26. 无害的保险（预热一次、加上限）可以留，但**注释里只写「保险」，不写机理** ——
    写了机理，下一个人就会把它当已证事实往上叠。

## 27 · 「不报错、只是画错」是这类项目的主要 bug 形态
静态检查、类型、构建、e2e 全绿，画面照样是错的。R19 一轮就撞了四个，全部只有**出图**才能发现：
叙事时钟用错钟、首帧补齐堵死渲染、y 轴翻转、半径没随布局校尺。
**推论：图形项目的验收下限是"看图"，不是"门绿"。** 门只能证明没崩，证明不了画对。

## 28 · 一个用错的量，会被用在好几个地方；症状只指向其中一处
`elapsed += dt`（夹持后步长）这个错，同文件里 `idleSince` 的注释**已经写明白了**
（"空转判据必须用真实墙钟"）——当时只修了空转判据那一处消费点，叙事时钟原样留着，
又活了很多轮。**判据：修「量算错了」类 bug，必须 grep 该量的全部消费点逐个判，
不能只修症状指向的那处。注释里写着的教训不会自己扩散到别处。**

## 29 · 把「按帧累加」改成「按墙钟」，必问一句慢起步会要求你一次做多少事
改完立刻长出新 bug：初始化的两秒在第一帧一次性要求补落 85 滴 ≈ 2000 次绘制，
渲染线程当场堵死，症状是**截图超时**（页面 200、无报错、canvas 在位，最难归因的形态）。
配套永远是**每帧预算上限**：快设备永不触顶，慢设备只是变慢不会卡死。

## 30 · 坐标系翻转的症状极具迷惑性：有内容、无报错，只是全在对面
引擎原点左下、CSS 左上。六条墨带各自落到镜像位置，画面"看着挺像回事"。
认出它靠的不是眼睛，是**数量反推**——"哪一团能有 502 滴那么大"，
对上 Codex(220)+Claude Code(282) 才确诊。
**判据：画面异常时先找一个能算出数量的锚点去反推归属，别靠看。**

## 31 · 换布局必须重新校尺，旧参数的正确性不传递
散点时代的半径 `0.011+r*0.038` 在二维散布下正确；改成六条墨带后，
一滴的直径（0.04~0.096）糊住 2~4.5 天（一天只有 0.0215 宽），密度反而读不出来。
**判据：任何"相对尺寸"参数都隐含一个它当初相对的东西。那个东西变了，参数必须重算。**

## 32 · 信息映射必须可读，否则和没映射一样
把撒点换成台账坐标只完成一半——不加轴标，"纵轴是席位"在画面上根本看不见，
仍然是拿构图冒充信息。**判据：做完映射问一句「不看代码的人，能从画面上读出这条轴是什么吗」。**

## 33 · 出图验收的顺序：先 commit 后跑门 = 顺序错
R18 那笔是改完直接 commit，门在之后才补跑。门要在 commit **之前**跑完并贴 rc，
否则"绿"是关于上一个版本的声称。

## 34 · `astro check` 不等于 `astro build`；commit 只能挂在 build 之后
`astro check` 对一个根本编译不过的 `.astro` 报 0 errors（对象字面量被函数声明截断、`getStaticPaths`
引用作用域外的常量、重复 import，三种它都不报）。凡改 `.astro`，验证下限是 `pnpm build` rc=0。
**判据：`git commit` 必须写在 `pnpm build && <门> &&` 之后，顺序不是依赖，`&&` 才是。**

## 35 · Astro `getStaticPaths()` 在独立作用域求值，只认 import
frontmatter 顶层的 `const` 对它不可见（运行期 `X is not defined`，check 零报错）。要在构建期跑的断言
（文案表闭合之类）必须放进独立模块 import 进来——顺带也就成了单源。

## 36 · 脚本化替换的命中断言只验「每处命中」，不验「合起来还成立」
把 `const X = {` 上提、表体留在原位，两处替换各自命中、组合出坏结构。护栏的已知盲区：
**跨行块的搬移要整块搬（含闭合），搬完 build 一次。**

## 37 · zsh 未引号变量不分词
`node x.mjs $ARGS` 在 zsh 里整串是一个参数（reducer 报"未知参数 --codex … --top 600"），
而我一度以为台账已重生成。传参用数组：`A=(--a b --c d); cmd "${A[@]}"`。

## 38 · 席位「不通」先做直连 vs 代理双路探测，再定性
agy 与 dots 同时 `Connection reset`，看似两个席各自坏了；`curl` 双路一测：直连境外三站全 rc=35，
走代理 Google 通——是「本机直连外网」这个前提失效，不是席坏。wrapper 硬剥代理时补 opt-in 逃生门
（`AGY_ALLOW_PROXY=1`，镜像 `APIDIRECT_ALLOW_PROXY`），负控仍 RST、正控 OK 才算修好。
**判据：报「对方挂了」之前，同链路换一个已知能通的端点跑一次，一条命令分开两种结论。**

## 39 · 竖滚驱动横移的手卷：验收是三态门，不是"看着会动"
正控：桌面滚到区间末尾 progress≈1 且 `translateX ≈ p·(stripWidth − viewport)`；
负控 A：窄视口 `transform:none`；负控 B：reduced-motion `transform:none` 且 sticky 退为 static。
少了负控，一条写漏的媒体查询会让手机端也横移而无人发现。sticky 高度别取整屏：内容只占上半时
是"顶着上沿"的默认布局味——封顶到内容高度附近并把 strip 垂直居中。

## 40 · 门全绿 ≠ 构图成立：出图后自己先看一遍，再派审
手卷首版 22/22 全绿，截图一看五跋浮在空纸上。**e2e 断言的是行为与数据，不是审美；
每幕落地后先自己读一张图，再把图交给审计席，别把"自己没看"外包成"等审计说"。**

## 41 · author 层的 `display:` 会盖掉 UA 的 `[hidden]`——属性绿、截图红
`.fallback { display:grid }` 与元素上的 `hidden` 同时存在时，author 规则（0,1,0）赢过 UA 的 `[hidden]{display:none}`，
降级文案**永远显示**。属性层（`data-ready=1`）与 e2e 全绿，只有截图看得见，连着两轮被归因成"资源争用伪影"。
**给 hidden 元素定 display 的地方，同笔写 `.x[hidden]{display:none}`；显隐断言用 computed 可见性（`toBeHidden/toBeVisible`）不用属性。**
归因反例：截图里出现某状态而探针说没有，先怀疑"这状态是不是根本没被隐藏"，再谈资源。

## 42 · 绝对定位的装饰线宽度取决于它的包含块，不是你以为的画心
`.band { position:absolute; display:inline-flex }` 里的 `::before { left:6.5rem; right:1rem }`：包含块只有标签那么宽，算出来负宽——线"不存在"，
两轮审计都报"不可见"，加浓颜色无效。**装饰线先量 `getBoundingClientRect().width`，再谈透明度；让包含块横贯画心（`left/right` 同时给），线做 flex 填充项由布局给宽。**
