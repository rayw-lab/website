## 0. 结论先行

- **当前视觉 rubric 自评：41.5 / 100**（逐项证据见 §4）。工程底盘（挂载策略、出口体系、程序化管线、双后端）是竞品级的，**视觉呈现是全 Loop 最弱轴**：黑天空、灰盒锥桶、五彩纸屑式窗色、无街道级霓虹，整帧读作「开发沙盒」而非「赛博科技城」。
- **综合分敏感度**：按 Loop 口径（视觉占 25%，其余四轴以 A4 审计数据代入 ≈99/100/100/100），综合分 ≈ 74.75 + 0.25 × 视觉分。当前视觉 41.5 → 综合 ≈ **85.1（贴线）**；视觉提到 65（§6 Tier A）→ 综合 ≈ 91；提到 85（Tier A+B+C）→ 综合 ≈ 96。**视觉轴每 +4 分 = 综合 +1 分，是当前 ROI 最高的提分轴。**
- 到视觉 85 分的路径拆成三个梯队（§6）：Tier A 十件低成本改动（多为引擎侧调参/小件 + 纯 CSS/DOM）→ 65.0；Tier B 五件引擎-中改动 → 76.6；Tier C 打磨批 → 85.7。

## 5. 自评说明（为什么这么低，哪里不背锅）

1. **不背锅项**：挂载策略/出口体系/A11y/加载工程全部竞品级（A4 审计已实证），rubric 刻意不重复计——本量表只量「看起来怎么样」。
2. **软件渲染折扣**：headless SwiftShader 无 MSAA、色调映射略偏——但 bloom/反射/阴影全在跑（Quality 0 console 实锤），构图/色彩/密度/道具四类问题与渲染器无关，真机不会自愈。
3. **最重的三项失分**：V2 霓虹密度（-8.4）、V3 天空（-6.4）、V5 楼宇辨识（-7.0）——合计 -21.8，全部是「设计缺席」而非「实现劣化」，即可以按清单补齐。

## 6. 到 85 的最小改动清单（按 ROI 排序）

成本类别：**DOM** = 纯 CSS/DOM（零引擎）；**引擎-低** = 调参/小件（<100 行，零新资产）；**引擎-中** = 新子系统（100–300 行或新 canvas 纹理）；**资产** = 重截/新增资产文件。预算纪律：全部动作不得破 G-A′ 红线（壳 ≤90KB / 首包 ≤2MB / 循环动画配额）。

### Tier A：41.5 → 65.0（十件，全部低成本）

| 序 | 动作 | 触及 | 增量 | 成本 | 施工要点 |
|----|------|------|:---:|------|---------|
