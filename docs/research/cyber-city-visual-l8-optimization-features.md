## 0. 结论先行

1. 脑暴 **16 项**视觉特性（§3 总表 + §4 分项）：**P0 六件**（X1/X2 两波实模、X3 招牌叙事 v2、X4 统一光照校准、X5 入场编舞、X6 definitive shot + poster 收口）、**P1 十件**。P0 六件是 71→**~88** 的主承重结构；**88→98 尾段 = 全维 95+ 的 SOTD 段**（rubric 95-100 锚 = Bruno folio-2025 量级），由 X16 烘焙统一 spike + 逐维复评补洞承接，**须显式裁决勿在 Loop 内隐式承诺**——这是 rubric §6「75→85 尾段裁决」纪律的 98 版镜像。
2. **双北极星敏感度**：综合北极星 98 只需视觉 **92**（100×0.75 + 92×0.25 = 98.0）；视觉 92→98 的尾段投入只服务视觉轴自身北极星。建议在 §5 里程碑 M5（~88）后先做综合分核算，再对尾段（M6）单独裁决 ROI——两个 98 不要混在一张账里。
3. 三个立项裁量原则贯穿全篇：**① 密度先行**——V1+V4 合计权重 35%，且 AL5 条件 3 与 BL 双审已裁定「程序化打磨的 V4 上限已触达，突破口唯有实模」，P0 前两席全给实模管线；**② 光照统一是 90+ 段总闸**——tone mapping + 台账重校（X4）一改全改、单批次，必须等实模主体批合流、材质集合稳定后开（顾问件「预热结论必须基于最终材质图」同逻辑）；**③ poster/像素基线重签永远殿后**——中间批次一律挂「基线重签」显式标记，禁止批量重拍掩盖回归（AL 纪律）。
4. **关键翻案发现（V6）**：rubric A8 当年以「webfont 因 90KB 合计红线否决」拒了品牌字型；但现行 `scripts/audit-budget.mjs` 的 `FONT_RE` 明确**跳过字体**（C-3「不含字体」条款），master-plan 7.5 的 200KB 首页传输门同样不含字体——否决依据与现行预算口径不符。V6 90-100 锚点明文要求「字体有品牌级选型」，X11 予以预算内重开（守 LHCI 四项 100 不降）。

## 4. 分项细述

### P0 —— 98 路径主承重（六件）

- **方案**：严格承接 BL2 复审 §9 最小补洞四条：① 新候选 SHA 含 24 图回滚；② 让 1440×900 正常整帧直接读到「塔身/螺旋带 + 屋顶阶差」组合（加高加宽轮廓件或调整体量分布，不改相机/楼位）；③ settled 同参（同 player/camera/FOV/viewport）pre/post 整帧取证；④ GLB 字节变化则全链重跑资产解析/复现/Q0/Q2/abort/全量 e2e/exact-port LHCI。补洞收口后同批或紧后追加**第三栋 hero 实模**——选楼建议以「robot_idle 视锥或主干道驾驶动线可见」为第一标准（同时喂 V1/驾驶沿途密度），候选 `work-gallery` 或 `tts-cockpit` 楼。
- **预期维分**：V4 72→76±1（BL1 先例：单栋 hero +KTX2/PBR 带来 V4 70 段站稳；第三栋 + 补洞轮廓补齐「关键视角密度」证据）；V7 +2（螺旋车库图腾从放大可读升为整帧可读）。

#### X2 · 实模 Wave 3：首幕可视集立面套件

- **现状欠账**：V1 65 的第一扣分源与 V4 的「程序化盒体」判词同根——robot_idle 视锥内近中景楼全是程序化幕墙，无手工细节层。整楼替换成本不可控，但 Orion 的密度感主要来自**立面构件**（雨棚/管线/空调外机/广告灯箱/檐口变体）而非楼体本身。
- **方案**：**混合路径**——楼体保持程序化，Blender 产**模块化立面套件**（6-10 种构件，单件 ≤50-150KB KTX2 后），经 InstancedMesh 贴附到首幕视锥与主干道沿街楼面（1-2 draw call/构件类）。施工顺序：先产 robot_idle 可见楼清单（NDC 探针遍历，取证协议先行），按「首幕近景 → 首幕中景 → 主干道沿街」三圈推进。街角道具带（垃圾箱/配电箱/自动售货亭等 3-5 件）同批。
- **预期维分**：V1 65→72（近景层次从平铺变三层可读）；V4 +6±2（「关键视角密度达标」= 70-85 段中部的锚点原文）。
- **风险**：首幕帧变化触 R1——本批为显式基线重签批，VIS-03/poster 基线按审阅后更新流程走；draw call 增量过 O4 哨兵（+20% 阈值）；实例化贴附的楼面对位工时（写 slot 元数据进 buildings JSON，不硬编码坐标）。
