# 赛博城市 12 栋楼视觉交互脑暴

## §0 总判断
- **现有基调**：低模（Low-poly）几何质感、暗调背景搭配高饱和霓虹点缀（Neon Tokens），整体呈现一种硬核、克制且功能导向的工业赛博朋克风。
- **应延续什么**：延续高对比度的「暗底+单色霓虹」数据终端视觉，保持以极客交互（如控制台、滑块、代码块）为核心的界面逻辑，避免花哨的装饰性元素。
- **应打破什么**：打破城市场景的宏观距离感，进入楼内应瞬间切换为「微距/特写」视角（如屏幕像素点、HUD 界面、机械组件特写），用高密度信息面板取代大范围空间漫游。

## §1 逐楼交互提案（按城区分组）

### 南口语言双子 (Language Twin Gate)
#### 1. Lingua Tower (多语种方案塔 - #49c5b6)
- **候选 A：巴别塔热力图（宿主改良版）**
  - **交互步骤**：1. 输入或选择一句测试文本 → 2. 界面瞬间展开 39 种语言的平行翻译 → 3. 语言列表按文字宽度/RTL 溢出风险自动排雷并高亮红色预警。
  - **视觉语汇**：终端机绿色字元、网格对齐、宽度热力图扫描光效。
  - **复用机制**：直接复用真实的 i18n 语料库数据。
  - **印证能力**：多语种座舱本地化工程的边界极限掌控力。
  - **复杂度**：M
  - **降级方式**：关闭扫描光效，直接静态显示宽度进度条。
- **候选 B：多模态声学频谱阵列**
  - **交互步骤**：1. 点击预设的不同文化场景 → 2. 展厅中心出现不同语种的动态声纹波形 → 3. 波形演变为具体的交互热区分布。
  - **视觉语汇**：粒子声波、#49c5b6 呼吸灯、全息质感。
  - **复用机制**：无。
  - **印证能力**：跨文化语音交互设计的理解。
  - **复杂度**：L
  - **降级方式**：静态波形图。
- **推荐**：候选 A。理由：最直观展示「语种灾难」，直接凸显本地化工程的痛点解决能力。

- **候选 A：声纹切割立面（宿主改良）**

  - **视觉语汇**：动态机械鳞片、#ff2d6f 荧光边缘、音频频谱。
  - **复用机制**：Web Audio API 结合 TTS Lab 的成熟音频流。
  - **印证能力**：TTS 调优与声音交互体验设计。
  - **复杂度**：M
  - **降级方式**：声纹变为点击后展开的静态频谱快照。
- **候选 B：参数化情绪罗盘**
  - **交互步骤**：1. 拖动情感滑块（喜/怒/哀） → 2. 界面中的三维声纹模型发生形变，并试听对应 TTS 声音。
  - **视觉语汇**：雷达图、流体形变、控制台旋钮。
  - **复用机制**：TTS Lab 的参数化音频接口。
  - **印证能力**：精细化 TTS 情绪控制能力。
  - **复杂度**：S
  - **降级方式**：去除 3D 形变，保留基础滑块与播放按钮。
- **推荐**：候选 A。理由：视觉冲击力极强，能迅速建立语音舱的技术体感。

  - **交互步骤**：1. 点击巨大的「点亮信标」按钮 → 2. 一道耀眼的光柱从屏幕中心直插云霄，点亮夜空 → 3. 伴随光芒散去，显示出微信号与邮箱。
  - **视觉语汇**：高亮光柱光晕、粒子散落、暗黑天空。
  - **复用机制**：无。
  - **印证能力**：仪式感设计。
  - **复杂度**：S
  - **降级方式**：点击按钮直接翻转显示联系方式。
- **推荐**：候选 A。理由：「调频」交互巧妙地替代了无聊的下拉框，把意图分流做得充满物理操作的快感 (S)。

## §2 横向机制具体方案
- **到达仪式（泊车→showcase→门禁扫描 View Transition）**：
  - **动作**：车辆驶入带有楼对应霓虹色的发光 `parkingBay` 圈。按 `E` 键触发。
  - **视觉**：0.8s 内相机快速平滑推进，越过车顶，锁定在建筑物发光的 Showcase 机位，形成强烈的景深模糊。定帧 0.4s 后，屏幕由上至下一道发光扫描线扫过（门禁扫描），通过 View Transition 无缝融入展厅页（黑底）或正文页（白底 C 横幅）。
- **探索进度点亮**：
  - **动作**：HUD 侧边栏有 12 个暗淡的六边形图腾。每次到达一栋新楼，对应颜色的图腾发出高光并被永久激活点亮。
- **12 栋全亮解锁 Observatory**：
  - **动作**：当 12 个图腾全部亮起，HUD 提示「Skyline Observatory 空间已授权」。
  - **视觉**：小地图新增金色信标。驶入后，相机拉升至上帝俯瞰视角，呈现全城带有连线和标签叠加的「站点数字拓扑地图」，展示玩家的行驶轨迹网。
- **子页回城**：
  - **动作**：在正文页或展厅点击"返回城市"。
  - **视觉**：触发类似「后退时空隧道」的缩放回退特效（View Transition），视角拉回正常驾驶机位，车底光圈闪烁两次。

## §5 风险提示
1. **踩「营销感/模板感」红线的风险**：动效一旦滥用粒子群集或无意义的 3D 旋转，就极易沦为廉价模板。对策是所有动画必须依附于「数据」（如行驶轨迹、语料宽度、证据等级），坚持绝对的"Data-Driven Animation"。
2. **与正文纸面风格打架的风险**：从 B 路线独立展厅（暗调赛博）跳入正文页（白底技术编辑部）时，会有巨大的视觉断层感。对策是在 B 路线的底部 CTA 区域提前融入白色的引导过渡块，或运用干净利落的 View Transition（例如屏幕拉开白纸黑幕），给访客做足心理建设。
