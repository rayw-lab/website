## 0. 结论先行

1. 脑暴 **16 项**非镜头游戏特性（§3 总表 + §4 分项），按「反馈 → 目标 → 挑战 → 人性化 → 传播」五层组织。**P0 六件**（G1 驾驶 HUD、G2 碰撞反馈包、G3 合成音效最小包、G4 目标线 v0、G11 分层新手引导、G12 进站预览卡）合起来直接回答指挥官痛点——「2 分钟实玩感受不到游戏性」：P0 全部落地后，用户在 **0:00–2:00 的每个 15 秒窗口**都至少收到一次新的反馈/目标/引导（§6 剧本逐秒对账）。
2. 三个立项裁量原则贯穿全篇：**① 2 分钟法则**——首两分钟感知不到的特性自动降 P2 以下；**② 可观测即立项条件**——每项特性开出候选 `world-*` 事件面（无埋点 = 不可登记，Loop 8 纪律）；**③ 降级可玩**——每项声明 KinematicFallback / Quality 2 / reduced-motion / 触屏四个降级态，禁止「高配专属玩法」。
3. 与镜头 F1–F11 的关系是**互补不重叠**：镜头批次管「看什么」（取景/tween/深链帧），本篇管「做什么、听什么、得到什么」（输入反馈、目标、挑战、成长、幽默）。两处显式对接点只有四个（§5）：G4 目标线消费镜头 F4 首驶引导的帧内 POI 光圈、G12 预览卡与镜头 F1/F5 进站前奏共享触发圈时序、G14 分享钩子复用镜头 F2 `?shot=` 深链、G16 移动包与镜头 F8 竖版探针同批取证。
4. 最大的单点收益判断：**音效层（G3）是全站当前值最被低估的缺口**——代码里音频字节数为 0（folio 移植时整层砍除），而 Bruno 拆解证明声音层是「玩具感」的一半来源；WebAudio 纯合成方案可做到**零资产字节**，不碰任何体积预算。
5. 纯静态站边界：每日排行榜、全球留言（Whispers 类）、动态 OG 图全部需要后端/边缘函数，**一律 P3 冷板凳**，本批次不为其引入任何服务依赖；本地 PB（localStorage）覆盖 80% 的成就感需求。

## 1. 设计原则

1. **2 分钟法则**：指挥官验收口径就是 2 分钟实玩。每项特性必须回答「首两分钟内用户在第几秒、以什么形式感知到它」；答不出的进 P2/P3。
2. **教学即玩耍**（Bruno 拆解结论 #1）：引导永远是第二道保险——第一课靠变形仪式自播，第二课靠撞楼，第三课靠触发圈光环。提示 chip 只在「用户 N 秒内没自己发现」时出现，出现过一次且键位被使用过即永久消失（localStorage）。
3. **diegetic 优先，DOM 兜底**：能长在世界里的反馈（标牌闪烁、光柱、测速牌）优先于屏幕 UI；但速度计/目标 chip/预览卡这类高频读取信息用 DOM overlay（`Reveal.ts` 先例：可访问、零 WebGL 成本、e2e 可断言）。
4. **可观测即立项条件**：每项特性附带候选事件（沿用既有 `world-reveal` / `world-transform:*` / `world-drive-start` / `world-poi` 的 `world-` 前缀 + `game.events` → `lab:analytics` CustomEvent 通路）；字段命名与会话时间线归 CC-OBS-DES 冻结，本篇给出事件名 + 最小 payload。
5. **失败必须便宜且好笑**：respawn（R 键已有）永远 1 秒内回到可玩状态；一切失败态（掉出世界、翻车、连撞）配轮换幽默文案——把「物理引擎的破绽」转化为「玩具的性格」（Bruno learning-by-crashing 的镜像面）。
6. **配额与恒等**：碰撞火花/收集爆点/成就 toast 全部是事件驱动一次性动画（不占 CITY-03 循环 ≤3 席）；一切特性不触碰 `ritual_idle` 恒等合同；音频/HUD 不改变 robot_idle 帧渲染路径。
7. **降级四轨**：KinematicFallback（无 Rapier：物理道具玩法退化为计时/视觉态）、Quality 2（粒子反馈减档、attract/闲置类关闭）、reduced-motion（震屏/脉冲改瞬时高亮）、触屏（键位动作全部有触屏等价物或显式不可用说明）。

## 4. 分项详述

### 反馈层（moment-to-moment：撞、开、听）

#### G1 · 驾驶 HUD 两件套 —— P0

- **玩法**：`driving` 态右下角常驻极简 HUD：①速度读数（km/h，大字）+ 速度条；②boost 状态条（Shift 按住充能视觉 + 冷却）。car_ready 淡入、进站/回 robot 淡出；FPV（V 键）下位置不变。风格沿用 `Reveal.ts` 的霓虹胶囊系（青边框 + 发光文字），DOM overlay 实现。
- **用户价值**：速度感是驾驶乐趣的一半——没有读数，boost 的 +9° FOV 推背（FPV eng note）只有「感觉」没有「证据」；HUD 同时是 G4 目标 chip、G6 收集计数的挂载宿主（一次搭壳，三处受益）。
- **2min 可感知**：~0:12，首次 W 起步即见读数跳动。
- **实现成本**：低。速度信号已有单源（`focusPointSpeed` / `__worldSpike.state()` 遥测先例），DOM 更新按 5Hz 节流（非逐帧），零 WebGL 改动、零 poster 风险。降级：reduced-motion 去掉数字滚动动画；触屏同样显示。
- **可观测事件**：`world-hud`（`{visible: boolean}`，状态切换时）；HUD 数据本身不埋点（高频），供 e2e 断言的 `data-world-hud` DOM 镜像。
- **红线**：robot_idle / transforming 态 HUD 必须 `hidden`（poster 帧零新增像素）。

#### G2 · 碰撞反馈包 —— P0

- **玩法**：车撞楼/道具时三通道反馈：①撞点一次性霓虹火花爆点（4–8 枚 sprite，事件粒子不占循环配额）；②相机微震（复用变形仪式 `ritualCam` 落地微震通道，幅度随撞击强度缩放）；③HUD 速度条红闪一帧。强撞（速度 > 12m/s）追加 G3 的碰撞音。
- **用户价值**：Loop 8 痛点原文「按键/碰撞/变形/驾驶即时反馈」——目前撞楼只有物理减速，无任何视听确认，是「感觉不像游戏」的最大单因子之一。Bruno 第二课「会撞」全靠碰撞反馈成立。
- **2min 可感知**：~0:25，出生点在十字路口，新手首分钟撞楼概率接近 100%。
- **实现成本**：中。`PhysicsVehicle.ts` 移植时明确砍除了 folio 的 `onCollision → audio.hitDefault` 钩子（文件头注释自认），需接回 Rapier contact 事件并整形为 `{position, impulse, speed}`；火花 = TSL 一次性 sprite 池；微震复用既有通道。**降级**：KinematicFallback 无接触事件——用「速度骤降 > 阈值」启发式近似触发（弱化版）；reduced-motion 关微震、保留火花与红闪。
- **可观测事件**：`world-collision`（`{speed, impulse, nearBuildingId?}`，节流 ≥300ms）——同时是 G10 连撞吐槽与 G13「碰碰车」成就的数据源。
- **红线**：微震只作用驾驶态相机，ritual/robot_idle 路径零触碰。

#### G3 · 合成音效层 —— P0（v0 三音包）/ P1（v1 引擎循环）

- **玩法**：WebAudio 纯合成（零采样资产）。**v0 三音包**：①变形 whoosh（噪声扫频 0.8s，对齐仪式四拍）；②碰撞 thump（低频正弦 + 噪声瞬态，强度随 impulse）；③E 键进站确认音（双音上行）。**v1 追加**：速度驱动引擎哼鸣（振荡器频率映射车速，boost 加谐波）、收集叮声、成就音。右上角常驻静音钮（默认开，localStorage 记忆），首次用户手势（既有 Space/CTA 或首个 WASD）解锁 AudioContext——不违反 autoplay 政策。
- **用户价值**：全站音频字节数当前为 **0**；Bruno 拆解证明声音层贡献「玩具感」的一半（载具是全站最富声源）。合成音色天然贴合赛博题材，且零资产 = 零体积预算冲突。
- **2min 可感知**：~0:05，变形 whoosh 是用户听到的第一个声音——「这个站有声音」本身就是 2 秒内的惊喜。
- **实现成本**：中。新子系统 `Audio.ts`（振荡器/噪声源 + 主增益 + mute 开关），v0 三音各 ~20 行合成参数；无资产加载、无解码等待。**降级**：`prefers-reduced-motion` 不联动声音（口径独立），但提供 mute；Quality 档不影响（CPU 合成开销可忽略）；iOS 静音键行为遵浏览器默认。
- **可观测事件**：`world-audio`（`{enabled: boolean, source: 'auto'|'user'}`）——回答「多少用户主动关声音」。
- **红线**：AudioContext 创建必须懒（首手势后），不改首包/LHCI；mute 钮进 e2e 断言。

### 目标层（去哪、为什么去、去了得到什么）

#### G4 · 目标线 v0「下一站」导视 —— P0

- **玩法**：car_ready 即在 HUD 顶部出现目标 chip：「下一站 · 概念车库 120m」（楼名 + 实时距离 + 城区色点）；同时目标楼 parkingBay 泊车光圈提亮 + 升起一根霓虹光柱（静态发光柱，非循环动画）。到站（进触发圈）→ chip 打钩 → 链上下一站。访问链数据驱动：`world-pois.json` 扩展段按「东城出行 → 南口语言 → 北城 AI → 东南作品 → 西南个人」城区顺序排 5 站主链（覆盖 5 城区各 1 栋），完成主链 → chip 变为「自由探索 · 已解锁巡访护照」。**非强制**：无视目标线一切照常（SRD「世界永远能开」的目标版）。
- **用户价值**：Loop 8 痛点「目标感缺失」的正面解——folio 的探索感 = 地标可见 + **有理由去**；three-story-controls 的 POI 故事线思路移植到「驾驶去下一站」而非「镜头飞下一站」。同时给镜头 F4（首驶引导帧内「最近 POI 光圈」）提供语义：那个光圈就是第一站。
- **2min 可感知**：~0:08，car_ready 交接后 chip 与光柱同帧出现。
- **实现成本**：中。chip = G1 HUD 壳挂载；距离 = 玩家坐标与 bay 坐标平面距离（每 5Hz 更新）；光柱 = NeonMaterials 静态材质柱（不占动画配额）；链推进 = Areas 既有 boundingIn 事件消费。**降级**：reduced-motion 光柱不脉冲（恒亮）；触屏同样可玩。
- **可观测事件**：`world-quest`（`{step, targetId, action: 'shown'|'reached'|'chain-complete', elapsedMs}`）——首两分钟流失点分析的主漏斗。
- **红线**：主链不锁任何楼（12 栋触发圈全程可用）；chip 可点击折叠（不想被指挥的用户一键收起，记忆偏好）。

#### G5 · 巡访护照 —— P1

- **玩法**：每栋楼首次进站（E 确认）→ 护照盖章 toast（楼色霓虹章 + 「3/12」计数）；HUD 角落常驻迷你计数；全 12 章 → 「城市通」成就 + Contact Beacon 光柱变金（世界级奖励，静态换色）。localStorage 跨会话持久。
- **用户价值**：把 12 栋楼从「地图点位」变成「收集面板」——回访动机（Bruno 成就墙的 POI 特化版）；对招聘官动线：盖章顺序即作品集浏览路径，`world-poi` 序列 = 内容漏斗数据。
- **2min 可感知**：~0:45，首次进站即盖第 1 章；「1/12」暗示还有 11 个理由继续玩。
- **实现成本**：低-中。进站事件已有（`world-poi`），加持久层 + toast 组件（与 G13 共享 toast 壳）。**降级**：全轨可用（纯 DOM + localStorage）。
- **可观测事件**：`world-passport`（`{buildingId, ordinal, total, sessionOrdinal}`）+ `world-passport-complete`。
- **红线**：localStorage 不可用（隐私模式）时静默降级为会话内计数，不报错不弹窗。

#### G6 · 收集品：霓虹数据芯片 —— P1

- **玩法**：全城布 12–16 枚悬浮「数据芯片」（六边形霓虹片，缓慢自旋——共享单一循环动画席位或用静态 + 事件闪光规避配额），驶过即收（触发圈半径 3m）：收集爆点 + 叮声 + HUD 计数 +1。布点策略：出生动线 20m 内埋 3 枚（教学：原来能捡东西），其余沿走廊、桥下、楼后死角引导探索盲区。全收集 → Now Signal 塔顶天线点亮彩蛋 + 成就。
- **用户价值**：探索的即时糖——目标线（G4）给「主干道理由」，芯片给「拐进小巷的理由」；folio 的 cookie/柠檬摊全球计数器的单机版。
- **2min 可感知**：~0:20，出生前方第一枚芯片在首驶直线上。
- **实现成本**：中。布点数据进 JSON（新 `collectibles` 段）；触发 = Zones 圆柱复用；收集态持久 localStorage。**降级**：KinematicFallback 无影响（触发圈非物理）；Quality 2 减发光强度；reduced-motion 停自旋（恒亮姿态）。
- **可观测事件**：`world-collect`（`{chipId, count, total}`）+ `world-collect-complete`——布点热力 = 探索范围的直接度量。
- **红线**：芯片不进 robot_idle 首幕取景框（布点避开 poster 视锥,数据可校验）；总渲染成本 = 实例化单 mesh。

### 挑战层（驾驶乐趣的「有难度」面）

#### G7 · 锥桶挑战：AutoDrive 试炼场 —— P1

- **玩法**：AutoDrive Lab（智驾实验楼,语义天然匹配）前庭布 8–10 只物理锥桶 slalom 阵 + 起终点霓虹门。驶过起点门自动开表（HUD 计时浮层），终点门收表：显示用时 + 碰倒锥桶数（每倒 +1s 罚时）→ 本地 PB。锥桶被撞飞是**核心笑点**（物理喜剧,Bruno 保龄球同构）；场边一键「重摆」（锥桶归位 + 清表）。
- **用户价值**：Loop 8 痛点「驾驶乐趣（非纯沙盒）」的正面解——第一个真正「可输可赢」的玩法；撞锥桶的物理反馈同时是 G2 碰撞包的最佳展示台。
- **2min 可感知**：~1:30，需 G4 目标线第一站把用户带到东城（概念车库隔壁即试炼场,顺路可见）。
- **实现成本**：中-高。锥桶 = Rapier dynamic 刚体（低模 8 面锥 × 实例化）；门 = Zones 平面带；计时/罚时/归位状态机 ~150 行。**降级**：KinematicFallback 无 dynamic 刚体 → 锥桶转静态障碍（碰撞 = 穿过 + 罚时判定仍走触发圈,可玩性保留、喜剧性降级）；reduced-motion 计时照常。
- **可观测事件**：`world-challenge`（`{id: 'slalom', action: 'start'|'finish'|'reset', timeMs, knocked, pb: boolean}`）。
- **红线**：锥桶物理体休眠管理（远离时 sleep,防常驻物理开销）；不进首幕视锥。

#### G8 · 计时圈 Neon Circuit —— P2

- **玩法**：内环四角楼之间的环路设 4 个检查点门（起终点 = 十字路口）,依序过门成圈计时；HUD 显示分段 delta（绿快红慢 vs PB）。完赛 → PB 持久 + G14 分享文本。幽灵车/每日排行榜 → P3（后端）。
- **用户价值**：复玩钩子之王（Bruno 实录「和儿子玩赛道想不通别人怎么跑进 20 秒」）；但**首两分钟感知不到**（新手不会立刻想竞速）,故让位 G7 排 P2。
- **2min 可感知**：否——设计为第 3 分钟起的留存层。
- **实现成本**：中。门 = Zones 复用 + 依序状态机；分段 UI 挂 G1 HUD。**降级**：全轨可用。
- **可观测事件**：`world-challenge`（`{id: 'circuit', action, timeMs, splits[], pb}`）。

#### G9 · 测速标牌 speed trap —— P1

- **玩法**：霓虹大街东段立一块「雷达测速牌」（TextCanvas 动态纹理,既有能力）：车接近时实时显示你的 km/h,驶离显示本会话最高速；超 90km/h 牌面闪「SPEED DEMON ⚡」+ 成就。牌子偶尔吐槽慢车（「这速度…是在找停车位吗」）——G10 幽默系统的世界内出口。
- **用户价值**：低成本高谈资（Bruno 教训 #12 的正面执行）；把 boost 从「按了 Shift」变成「刷出数字」——速度感的世界内证据,与 G1 HUD 互为表里。
- **2min 可感知**：~0:40,霓虹大街是出生点东西主轴,首分钟必经。
- **实现成本**：低。TextCanvas + 距离检测 + 速度读数,单文件；文案表纯数据。**降级**：全轨可用；reduced-motion 去闪烁。
- **可观测事件**：`world-speedtrap`（`{kmh, isRecord}`,节流）。

### 人性化层（引导、失败、可及性）

#### G10 · 失败幽默包 —— P1

- **玩法**：三个失败态接住并逗笑：①**掉出世界**（killElevation respawn 已有）→ status 行轮换文案（「深渊不收简历,已把你捞回地面」「重力也是一种用户反馈」）；②**连撞**（10s 内 ≥3 次 `world-collision`）→ 最近楼的标牌闪烁 + 吐槽（「楼没事,楼见得多了」）；③**翻车检测**（roll 角持续 > 阈值 2s）→ hint 弹「按 F 悬挂弹跳翻正」（F 键既有但零引导,是当前最深的隐藏功能）+ 「翻车艺术家」成就。文案表纯数据（中英双语,随机不重复）。
- **用户价值**：把物理引擎的破绽转化为性格——失败瞬间是情绪最脆弱也最容易被幽默收买的时刻（Bruno 掉深渊祭坛计数器同构）；F 键教学顺手解决「翻车即死局」的真实挫败。
- **2min 可感知**：~1:00,首次 R 键或首次翻车即触发。
- **实现成本**：低。全部复用既有通道（respawn 事件、status/hint DOM、collision 事件、车体姿态读数）；文案表 ~30 条。**降级**：全轨可用。
- **可观测事件**：`world-fail`（`{kind: 'void'|'pileup'|'rollover', humorId, respawnUsed}`）——「哪种失败最高频」直接指导后续手感调参。
- **红线**：吐槽频控（同类 60s 冷却）,不能从幽默变骚扰。

#### G11 · 分层新手引导 —— P0

- **玩法**：状态机驱动的 hint chip 体系,升级既有 `Reveal.ts` 单条提示：①**car_ready**：「WASD 驾驶 · Shift 加速」（已有,保留）；②**首驶 15s 未用 Shift**：boost 提示；③**首次入触发圈**：G12 预览卡自带 E 提示（引导即卡片）；④**驾驶 20s 未撞未进站**：「试试 V 切换车内视角」；⑤**翻车**：F 键提示（G10 联动）。**铁律**：每条 hint 绑定一个动作,动作首次使用即该条永久消失（localStorage `input-first-use` 表）;全部 hint 可被 5s 无操作以外的任何输入打断。移动端换 nipple 专属文案。
- **用户价值**：功能维 F1「2 分钟内理解我是谁/能干什么/下一步」的直接执行;当前 V/F/R 三键零引导 = 三个已建成却没人知道的功能——引导是**已有投资的变现**,不是新功能。
- **2min 可感知**：~0:03 起全程陪跑,且越玩越安静（用过的键不再提示）。
- **实现成本**：低-中。hint 队列 + 条件表 + 首用记忆,~120 行;DOM 壳复用。**降级**：reduced-motion 去滑入动画;触屏文案分轨。
- **可观测事件**：`world-onboard`（`{hintId, action: 'shown'|'consumed'|'expired'}`）+ `world-input-first-use`（`{action, tSinceDriveMs}`）——「哪个键最晚被发现」是引导迭代的唯一依据。
- **红线**：hint 不遮 HUD 不遮预览卡（布局分区）;robot_idle 态零 hint（poster）。

### 进站层（POI 玩法闭环）

#### G12 · 进站预览卡 —— P0

- **玩法**：驶入楼触发圈 → HUD 底部滑入预览卡：楼色边框 + 中英楼名 + 一句话职能（buildings JSON `title`/职能字段已有）+ 「E 进站」键帽;停稳（速度 < 2m/s）后卡片充能条 0.6s 蓄满（视觉确认「可以按了」）;E → 确认音（G3）→ 进站（现直跳,CC-P1 overlay 后无缝升级）。驶离圈卡片滑出。深链回流:进站后返回世界（浏览器后退）→ 卡片显示「已盖章」态（G5 联动）。
- **用户价值**：当前进站 = 世界内小键帽 + 突然整页跳转,断裂感是 POI 动线最大伤口;预览卡补上「我要进的是什么」的信息层与「停稳-确认-进入」的仪式层——Orion 进站的**信息面**（镜头 F1 管**画面面**,两者共享同一触发圈时序,可独立先行）。
- **2min 可感知**：~0:50,G4 第一站到站即见。
- **实现成本**：低-中。Areas `boundingIn/Out` 事件已有,卡片 = DOM 组件消费 buildings JSON;停稳判定与镜头 F5 泊入定帧同参数（`v < 2m/s · 0.6s`,一处定义两处消费）。**降级**：全轨可用;reduced-motion 去滑入充能动画（直显直确认）。
- **可观测事件**：`world-poi-card`（`{buildingId, action: 'shown'|'engaged'|'entered'|'dismissed', dwellMs}`）——「进圈却不进站」的流失率是 POI 吸引力的直接度量,补齐既有 `world-poi`（只记进站成功）看不见的漏斗上半段。
- **红线**：卡片不抢驾驶输入焦点;E 键 categories 口径不变（wandering/driving）。

#### G13 · 成就 toast 系统 —— P1（toast 内核）/ P2（面板）

- **玩法**：v0 = 12–15 条轻成就,达成即右上 toast（霓虹章 + 名称,3s 淡出）:首次变形/首次 boost/首次 FPV/首次进站/护照 5 章/碰碰车（撞 10 次）/翻车艺术家/SPEED DEMON/锥桶完赛/全芯片…… localStorage 持久。v1 = ESC 或 HUD 图标开成就面板（含达成时刻,Bruno 解锁计时同构）。命名走幽默向,和 G10 同一文案系统。
- **用户价值**：把玩家自发行为逐条「盖章确认」——行为心理学的免费多巴胺;同时成就表 = 功能维 F6 的天然量化载体（审计可数「2 分钟内平均解锁几条」）。
- **2min 可感知**：~0:15,「初次变形」toast 是第一条,几乎人人必得。
- **实现成本**：中。成就条件表（纯数据,消费既有 + 本篇新增事件）+ toast 壳（G5 共享）+ 持久层;面板归 v1。**降级**：全轨可用。
- **可观测事件**：`world-achievement`（`{id, tSinceRevealMs, sessionOrdinal}`）。
- **红线**：toast 频控（并发合并,最多同屏 1 条）;成就条件只消费事件面,不进引擎逻辑。

### 传播层（社交分享钩子）

#### G14 · 分享钩子 v0：成绩文本 + 深链 —— P2

- **玩法**：三个分享出口,全部零后端:①锥桶/计时圈 PB toast 附「复制成绩」→ 剪贴板文本「我在王磊的赛博科技城 32.4s 跑完霓虹环线,你来试试 → {url}?poi=autodrive-lab」;②护照全章成就 → 复制「12/12 城市通」文本 + 首页深链;③每个预览卡长按/右键 → 复制该楼深链（`?poi=` 既有,镜头 F2 落地后自动升级为 `?poi=&shot=` 海报帧链接）。
- **用户价值**：V7 传播叙事的最低成本起步——文本 + URL 的分享转化率虽低于图片,但实现成本 1/10 且零隐私/体积风险;为镜头 F9 photo mode（P3 冷板凳）预铺分享动线,F9 解冻时只换 payload。
- **2min 可感知**：否——依附 PB/全章达成,天然后置。
- **实现成本**：低。clipboard API + 文案模板;深链已有。**降级**：clipboard 不可用 → 显示可选中文本框。
- **可观测事件**：`world-share`（`{kind: 'pb'|'passport'|'poi-link', channel: 'clipboard'}`）+ 深链落地侧 `?poi=` 已可归因回流。

#### G15 · 喇叭 + 世界回应彩蛋 —— P2

- **玩法**：H 键喇叭（合成双音,赛博「哔-啵」）;彩蛋:触发圈内按喇叭 → 该楼标牌闪烁回应一次;对 Now Signal 塔按 → 塔顶天线回闪摩斯「HI」。机器人形态按 H → 蜂鸣 + 头灯眨眼（不动 ritual 骨架,仅材质 emissive 事件脉冲——需确认不碰 poster 帧,若有风险则机器人形态禁用）。
- **用户价值**：无目的玩具按钮 = 玩具感试金石(Bruno 车喇叭是全站最高频「无意义但快乐」交互);「世界会回应你」是 folio 探索感的微观版。
- **2min 可感知**：需引导(键位表/G11 第 5 条候补)。
- **实现成本**：低。键位动作 +1(`horn`,categories driving/wandering)+ G3 音色 +1 + 标牌 emissive 事件脉冲。**降级**:静音态喇叭只有视觉回应。
- **可观测事件**：`world-horn`(`{context: 'street'|'poi'|'robot', responded: boolean}`)。
- **红线**：robot 形态回应若威胁 robot_idle 恒等,直接砍该分支(喇叭本体保留)。

#### G16 · 移动端可玩包 —— P2

- **玩法**：触屏三补齐:①HUD 追加触屏按钮组(E 进站/R 复位/V 视角——V 的触屏缺口 FPV eng note §3 已登记);②`navigator.vibrate` 碰撞/收集短振动(Android 生效,iOS 静默降级);③竖屏 HUD 紧凑布局(与镜头 F8 竖版探针同批取证)。nipple 摇杆既有,不动。
- **用户价值**：功能维 F5 移动端子项;移动流量的「可玩」底线——当前移动端能开车但进不了站(E 无触屏等价)是硬伤。
- **2min 可感知**：移动端用户全程。
- **实现成本**：中。按钮组复用 `toggleView`/`respawn`/`interact` 既有动作(零引擎改动);布局媒体查询。**降级**:本身即降级轨。
- **可观测事件**：`world-mobile`(`{control: 'e'|'r'|'v', via: 'touch'}`)——移动交互率 vs 桌面的直接对比。
