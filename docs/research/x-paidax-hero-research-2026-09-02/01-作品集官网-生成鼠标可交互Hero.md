### 实现第二屏"滚动控制视频"的交互（给 Codex 的提示词）

- 滚动进入第二屏后，内容固定在视口中，滚动控制视频进度。
- 向下滚动 → 视频向后播放；向上滚动 → 视频回退。
- 滚动区间起点对应第一帧，终点对应最后一帧。
- 完成该区间后自然进入下一屏，反向滚动时状态准确恢复。
- 不改变现有视觉设计和其他滚动交互。

实现方式：

- 使用 长滚动区间 + position: sticky，不要用 wheel + preventDefault 劫持页面滚动。
- 根据真实页面滚动位置计算 progress，不要依赖 wheel 的 deltaY 累加：

```ts
progress = clamp(
  -section.getBoundingClientRect().top /
  (section.scrollHeight - window.innerHeight),
  0,
  1
)
targetTime = progress * video.duration
```

- 使用 requestAnimationFrame 同步 currentTime，限制 seek 频率约 24～30 FPS，避免高频 seek。
- 等待 loadedmetadata 后读取 duration。
- 视频禁止自动播放和原生控制栏，并设置 muted、playsInline、preload="auto"、poster。
- 视频未加载、快速正反向滚动、窗口尺寸变化、移动端视口变化都要正常工作。
- 页面刷新后停留在第二屏时，也要根据当前滚动位置正确恢复视频帧。
- 组件销毁时清理所有监听和 requestAnimationFrame。
- 如果有文字、图片等动画，也统一由 progress 驱动，并集中配置动画区间。
