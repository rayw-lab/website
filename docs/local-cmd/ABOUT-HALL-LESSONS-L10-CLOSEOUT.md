# About 馆 L10 至收口经验

1. 全量失败必须保留原轮。定向复跑只证明当前受控条件，不能擦掉 97/2/10 的 attempt10。
2. Playwright 的 `webServer exited early` 需要沿启动器到真实进程核。Astro 7 的代理环境后台化会让端口已经 200、父进程却先退出；设置前台契约比增加 timeout 或 retry 更准确。
3. 隔离端口必须贯穿 Lighthouse 的全部 URL。只改 preview 端口会让采集静默回到 4321，测到另一个工作树。
4. 视觉审查的“缺失”先核采样输入。移动截图漏 `from=city&poi=` 会把正确的进站到达条契约判成产品缺陷；补对采样后再改产品。
5. 中文窄屏要在词组级处理断行。全局 `word-break: keep-all` 会制造溢出；只锁“复杂技术”和五字站名即可。
6. 动画高潮中段仍需一个可复述锚点。S6 的开场句和落点句可以交替淡入，但“回家”标题应全程留在画面上。
7. 长测试会被工具会话中断。终态判据是 Playwright JSON、聚合摘要和退出码三者同在；只剩 preview 进程不代表测试仍活着。
8. 构建告警按消费路径裁决。大模块若只在进入城市后按需加载、预算门合格，应具名登记；不能靠提高阈值消音，也不必为告警临时重构稳定主路径。
