# ADR-1 · 化身路线与兜底顺序

## 背景

章程已锁叙事骨架：展厅是「机器人的老家」，首屏人形态化身，滚动后解构为城里那台 `HeroRobot.glb`。真人照片原图尚未落盘（角色特征表已从两张参考照抽出，不等于 R 路线可开工）。W1 必须今天能跑管线。WBS-01 把首屏从章程草稿里的「工作台」改成场景库 S0「桥」，S6「回家」作过渡；LOCKED 纸 S0-T / S0-H / S0-R-v0 / S6-T 已出。本包只裁生产顺序、赛马份数、熔断、首屏场景、过渡唯一性。不重开：C+B+A、机器人是馆长不变形、文字不进 diffusion、不用外部引擎、i2v 本项目解禁。

## 选项与代价

| 选项 | 内容 | 代价 |
|---|---|---|
| **(a)** | T/H 先行赛马；照片落盘后 R 加入；三选一由磊哥人拣 | W1 当天开工；R 可能最终赢，T/H 前期资产部分作废；人拣前不能把任一形态写进 `about-hall-media.json` 当正式件 |
| **(b)** | 等照片；R 为唯一正式路线；T/H 只作降级 | W1 停工等 `NEEDS_LEIGE(照片)`；若 Grok 拒真人脸，正式路线真空；T/H 管线仍要建，所谓「只作降级」并不省工 |
| **(c)** | 双形态固定：首屏必须 R + 过渡到机甲；T/H 不做 | 叙事双形态本就已锁；「T/H 不做」= 无照片或拒脸时 W1 无法交付；与章程「拒脸则卡通/手绘先行」正面冲突 |

「双形态」有两层，必须拆开：页内叙事（人形态首屏 → 机甲）是章程已锁，不是本包选项；生产形态（R / T / H 用哪条出像素）才是本包要裁的。

## 裁决

**生产走 (a)：T 与 H 并行赛马开工，R 在原图落盘后加入，磊哥人拣一条正式路线；页内叙事维持「人形态首屏 + S6 回家成机甲」，T/H 不是可删的降级玩具。**

## 执行口径（可直接写进任务书）

1. **页内双形态（已锁，本 ADR 复述不重开）**  
   首屏 = 人形态化身（正式路线是 R 或 T 或 H 之一）。滚动进入 S6，人解构为光子，同机位凝聚成钛灰机甲（造型约束见 `HeroRobot` README：块面、青眼 `#49c5b6`、钛灰 `#5c6472`、工业橙 `#ff6b35` 点缀；无红蓝、无胸口车窗、无徽章、无变形车件）。馆内机甲不再变形。禁止第二段人→机甲或机甲→车。

2. **生产顺序**  
   - 立刻并行：S0-T 与 S0-H（`GO=yes`，不依赖照片）。  
   - R 的 GO 条件 = `~/studio-data-root/about-hall/ref/formal.jpg` 与 `selfie.jpg` 落盘 **且** sha256 写入 `GEN-RECEIPT`；角色特征表已存在 **不等于** R 可跑。  
   - 人拣前：T/H（及后到的 R）只进 `studio-data-root/about-hall/gen/`，**不**写入 `public/media/about-hall/` 正式文件名、**不**进 `about-hall-media.json`。  
   - 人拣后：赢家升正式件；落选者保留为该场景的兜底叶，不删盘、不改 LOCKED 纸。

3. **赛马样张 = 每条路线 first 帧 ×3，不是 ×5；也不是三条都出视频**  
   - 每条路线：`image_gen`（R 为 `image_edit`）first ×3，人拣 1 张再出 last ×3，再拣 1 对 first/last 才 `image_to_video`。  
   - 禁止三条路线各出一支 6s 视频再赛。身份与气质在静帧上判。  
   - 9:16 移动版只给赢家，赛马不做。  
   - 不选 5：多两张只加扩散方差，不加人拣信息量，且拖慢独立审计。

4. **熔断：3 连 REJECT 换路线，合理；单位必须是「叶」**  
   - 叶 = `S{n}-{形态}-v{k}`（同一场景 × 同一形态 × 同一提示词版本）。T 与 H 独立计，互不累加。  
   - 静帧审计 3 连 REJECT → 停该叶，该场景改走另一形态；不改同一 LOCKED 正文硬磕（改稿必须升版本号）。  
   - 静帧已 PASS 后的 i2v：先换种子，3 连 REJECT（形变/漂移）才换形态；不回改已 PASS 的 first/last 提示词。  
   - R 若返回真人脸限制：记 `DEFERRED_EXTERNAL(real-face)`，措辞最多再试 **2** 次，然后 T/H 转正。政策墙不是「再试一次就过」的叶，禁止拿 3 连去撞 ToS。  
   - 磊哥人拣之后：赢家 3 连 REJECT → 降到亚军，**不**重开三方赛马。  
   - `SEND_ACCEPTED` 后禁重发。生成路与审计路必须不同 lane；生成路自评无效。  
   - 熔断换路线 ≠ 整族 KILL（座舱 IMG-01 的整族杀掉在本楼过重）。W1 只要还有一条形态能过门就继续。

5. **首屏场景定案为 S0「桥」，工作台不定案为首屏**  
   - 绑定：定位语 / H1「在技术与落地之间架桥」。  
   - 硬约束：左 40% 负空间给 DOM 文案；工作台三屏几乎必然在 diffusion 里长出可读字形，撞零字铁律。  
   - 章程「首屏在工作台」是叙事草稿；场景库 S0 是生产规格。S1「工作台」留 W3 / 收官，不删。  
   - 出纸勘误（生成前必改，升 S0-T/H 的 motion 版本，不算重开场景）：last-frame 写角色「头向 **自己的左** 转看城市」（面对镜头时，城市在画面右侧 = 角色左侧）；S0-T / S0-H 的 motion 里「city on his right」与此冲突，改成角色坐标系与 last-frame 同文后再生成。

6. **S6「回家」是唯一的人→机甲过渡，且必须同机位同场地**  
   - W1 只产这一段过渡视频（10s）。W3 其余幕用别的单一主事件，不再做一次变身。  
   - i2v 护栏：S6 的 first 与 last 都在停机坪/机库，禁止把 S0 桥与机库塞进同一支视频（换场地 + 变身 = 主体漂移）。地理移动交给 W3 其它场景。  
   - S6 人形态跟随 S0 赢家：S0 定 T 则产 S6-T；定 H 则补 S6-H 纸再产；定 R 则先试 S6-R，3 连 REJECT 或恐怖谷则 S6 降到 T/H 亚军，**不**倒逼改 S0。真人首屏接到风格化机甲，主题上就是「回机器人的老家」，允许风格跳。  
   - 现有 `S6-T-LOCKED-v1.md` 在 T 赢或 R 降级时直接用；H 赢才新出 S6-H。

7. **人门**  
   赛马静帧只做 A 维预评（两席 |Δ|≤1）。正式人门 A ≥7 只打赢家的 6s 片 + poster，不打落选叶。

## 不重开清单

- C 全覆盖到达横幅 + B 展厅 + A 只给 Garage。  
- 机器人是馆长，馆内不变形。  
- 文字 / 年份 / 商标 / 真车前脸不进 diffusion。  
- 不用任何外部生图生视频引擎。  
- i2v 本项目解禁；护栏 = 固定机位 + 单一主事件 + first/last 双帧独立审计。  
- 本 ADR 已锁：生产顺序 (a)、样张 ×3、叶级 3 连熔断、S0=桥、S6=唯一变身。禁止下一轮把工作台抬回首屏、禁止「等照片再开工」、禁止「T/H 不做」。
