## 0. 结论先行（冻结清单）

1. **七维权重冻结**：F1 15 / **F2 20** / F3 15 / F4 15 / F5 15 / F6 10 / F7 10 = **100%**（§2.1）。入口文档 §3.1 提议合计 95% 非法，顾问修正 F2 提至 20%（指挥官 2min 实玩三连抱怨的最大公因子 =「按了没反应感」），本文件采纳冻结。
2. **三条口径铁律**（§1）：**脚本优先**（脚本动线内自然遇不到的功能不计分）、**反馈闭环才算数**（输入→响应→可感知确认三段齐，缺确认层按半价）、**F7 强制配套**（无埋点不登记的 rubric 化身）。
3. **脚本冻结**：S-2 v1.0（2 分钟指挥官复测口径）+ S-5 v1.0（5 分钟审计口径 = S-2 + 七条专项腿），脚本版本号进登记 JSON 溯源字段（§4）。条件腿（V 键 / `?shot=` / 进站前奏）在依赖合流前标记 skipped 留痕，不计分不伪造（§4.4）。

5. **与 score-loop 关系**：综合分五维权重**不动**；功能/性能是与综合分**并列**的北极星维度，不折算进五维；`quality-score.json` 的 `northStar` 只读汇总块归 CC-OBS-DES 落地（§7）。

## 1. 目的与口径铁律

**只测「2 分钟体验合不合格」**：交互可懂、反馈可感、驾驶有乐、POI 可玩、失败可恢复、行为可观测。**不测**视觉工艺（视觉 rubric v1.1 承载，防双计）、不测壳加载分（LHCI 承载）、不测状态机可达性（e2e 承载）。

**口径铁律**（对应视觉 rubric「帧优先」，v1.0 起为本 rubric 法条）：

1. **脚本优先**：功能必须在 §4 playtest 脚本的动线内被**自然遇到**才计分——「功能在代码里但 2min 脚本里遇不到」不计收益。发现性本身就是 F1/F4 的被测项：藏得太深 = 该维扣分，而不是换个脚本去凑它。
2. **反馈闭环才算数**：F2 的计分单元是「输入 → 世界响应 → 玩家可感知确认」三段闭环；只有状态变化、没有反馈呈现（视听/HUD/文案至少一样）的项按**半价**计。
3. **F7 是强制配套维**：Loop 8「不可观测 = 不可登记」纪律的 rubric 化身。功能面成熟后 v2 可降为 5% 让渡 F6，改权重必须升版本号（§8）。

**分值标定（全局锚）**：

- **90-100** = 「拿给陌生人 2 分钟，全程不用解释一句话」——可懂、可感、可玩、可恢复、可观测五面齐；
- **70-85** = 核心链路（变形→驾驶→进站）顺畅有反馈，但辅助面（提示再唤出、目标感、个别反馈层）有可数缺口；
- **50-65** = 能玩但平淡/靠猜——「工程通了、体验欠账」（对应指挥官 2026-08-27 实玩口径的现状段位）；
- **30-45** = 被试会卡住或误解主流程；
- **0-25** = 不可玩。

**反通胀**：逐维必须引用当轮证据（≥1 条 dump 事件 seq/t + ≥1 段录屏时间码）+ 锚点段落；与上轮分差 ≥±10 的维必须写差异说明（视觉 rubric §1 铁律 3 同构）。

## 2. 七维权重与 0-100 锚点（冻结）

### 2.1 权重表

各维 0-100 独立打分（5 的倍数，允许段内插值），**总分 = Σ(维分 × 权重)，四舍五入取整**。

| 维 | 权重 | 测什么 | 主证据源 |
|----|:---:|--------|----------|
| F1 首幕可懂 | 15% | 2min 内理解「我是谁、能干什么、下一步」——三问回答（§4.2 收尾） | 录屏 + 三问原文 |
| F2 操作反馈 | **20%** | 按键/碰撞/变形/驾驶/切视角的**即时**视听+UI 反馈（V 键腿 VEH 合流后生效） | 录屏逐帧 + dump 事件↔画面对齐 |
| F3 驾驶乐趣 | 15% | 速度感、视角（third/fpv）、复位友好、障碍/目标感（非纯沙盒） | 录屏 + dump counters |
| F4 POI 游戏化 | 15% | 进站可发现可完成、深链直达、楼=导航（对接 CAM F1/F2） | funnel.firstPoiIn/Interact + 录屏 |
| F5 人性化 | 15% | 提示消隐/再唤出、误触、失败恢复（翻车/卡墙/掉出）、reduced-motion、触屏 | S-5 专项腿 |
| F6 目标/进度 | 10% | 可选任务线/探索动机/成就感（非强制主线） | 录屏 + counters |
| F7 可观测完备 | 10% | 白名单事件接通率、dump 可导出、`#debug` 可用、CI 工件接通 | dump 自身 + CI 工件 |

> 权重推导（顾问 §2.1 采纳理由留痕）：F2 是 2min 实玩第一痛点故独占最大单维 20%；F1/F3/F4/F5 为体验四支柱各 15%；F6/F7 各 10%——F6 形态待 CC-FXN-BR 脑暴 + FXN-C4 落地（先给发育位），F7 是纪律维（成熟后可降）。合计 100%。

### 2.2 逐维锚点

#### F1 首幕可懂（15%）

被测：定位语可读、机器人显现、CTA「变形 · 巡航态 Space」可发现、状态文案（`[data-world-status]`）与键位提示（`[data-world-hint]`）被真的读到；收尾三问（我是谁 / 能干什么 / 下一步）。

| 分段 | 锚点 |
|:---:|------|
| 90-100 | 零解释自明：三问全对，且 0:15 前被试能说出下一步；CTA→状态文案→键位提示层层接力，无一步靠猜 |
| 70-85 | 三问 ≥2 对、下一步在 0:30 内被发现；个别提示要主动找（如 hint 淡出后不知如何再看一遍） |
| 50-65 | 三问答对 2 问但明显迟疑/有误解；或 CTA 靠误点才发现；状态文案在但没被读到 |
| 30-45 | 三问 ≤1 对；被试在首幕停留 ≥30s 不知道能变形/能开 |
| 0-25 | 完全不可懂：被试不知这是可交互世界 |

#### F2 操作反馈（20%）

被测输入面（S-2 动线内全量）：CTA/Space 变形（disabled + 进度 + 落地冲击）、WASD 加减速转向、Shift boost、Space/B 刹车、锥桶/墙碰撞、R 复位、F 悬挂跳、V 切视角（合流后）、E 进站。逐项按铁律 2 判「全额闭环 / 半价（缺确认层）/ 零分（无响应）」。

| 分段 | 锚点 |
|:---:|------|
| 90-100 | 动线内全部输入三段闭环、可感知延迟 ≤100ms 量级；碰撞/boost/复位有**专属**反馈（HUD 脉冲/toast/音画任一成体系）；dump 事件与录屏帧逐一对齐 |
| 70-85 | 核心输入（变形/驾驶/刹车/复位）闭环齐；半价项 ≤2（如撞锥桶只有物理弹开、无 HUD/音画确认） |
| 50-65 | 驾驶基本可感，但 ≥3 类输入缺确认层——「按了没反应感」开始出现（现状段位：碰撞无 HUD 反馈、respawn 无 toast、boost 只有速度数字） |
| 30-45 | 多数输入只有状态变化无呈现；被试反复重按怀疑失灵 |
| 0-25 | 输入经常丢失或无响应 |

#### F3 驾驶乐趣（15%）

被测：速度感（视角拉远/FOV/景物流动）、转向手感、急转/漂移可控性、third↔fpv 档差（合流后）、复位友好度、障碍与目标感（锥桶/道具是玩点还是摆设）。

| 分段 | 锚点 |
|:---:|------|
| 90-100 | 60s 自由驾驶结束时被试**主动要求继续开**；速度感明确、急转有乐趣不失控；翻车/卡墙 ≤3s 恢复零挫败；有至少一个「想再来一次」的驾驶玩点 |
| 70-85 | 顺手、速度感成立、复位友好；但目标感弱（开着开着不知道干嘛）或视角单一 |
| 50-65 | 能开但平淡：速度感弱/转向漂/障碍全是摆设——纯沙盒感 |
| 30-45 | 操控挫败：频繁打滑失控/卡墙且恢复困难 |
| 0-25 | 几乎不可驾驶 |

#### F4 POI 游戏化（15%）

被测：光圈/标点可发现性（S-2 1:30 起自然动线）、E/Enter/点按进站可完成、进站前奏（CAM F1，FXN-C3 合流后）、`?poi=`/`?shot=` 深链直达（S-5 腿）、「楼=作品分区」可被转述。

| 分段 | 锚点 |
|:---:|------|
| 90-100 | 光圈 30s 内自然吸引被试进站；进站有前奏与到达感（合流后）且落点正确；深链直达；被试能说出「每栋楼是一类作品」 |
| 70-85 | 可发现可完成、键帽提示读到、深链直达；但进站过程平淡（硬切/无前奏）或个别楼定位不明 |
| 50-65 | POI 系统在但发现靠运气（光圈不显眼/提示没读到）；或进站后「发生了什么」不明确 |
| 30-45 | S-2 动线内未自然遇到任何 POI 交互（铁律 1：代码在不计分） |
| 0-25 | POI 不可用 |

#### F5 人性化（15%）

被测五腿（S-5 §4.3 逐条）：①失败恢复（翻车 3s 自救 flipJump / 卡墙 R / 掉出 killElevation 重生）②提示系统（hint 消隐→再唤出；ESC 菜单→出口）③reduced-motion（终态直出、instant swap、文字状态可读、核心路径可完成）④触屏（摇杆驾驶 + 点标点进站）⑤误触无惩罚（变形中重复按/驾驶中按无关键）。

| 分段 | 锚点 |
|:---:|------|
| 90-100 | 五腿全过：任何失败 ≤3s 自动或一键恢复；提示可再唤出；reduced-motion 与触屏全流程可完成；误触零惩罚 |
| 70-85 | ≥4 腿过，剩余一腿是小缺口（如 hint 淡出后无再唤出键——现状：`Reveal.ts` 淡出后无 H 类唤回） |
| 50-65 | 失败恢复齐但辅助面缺一腿（reduced-motion 或触屏路径不完整） |
| 30-45 | 存在让用户彻底卡死的路径（掉出无重生/翻车无自救），或 reduced-motion 不能完成核心路径 |
| 0-25 | 处处陷阱 |

#### F6 目标/进度（10%）

被测：可选目标的存在与呈现（如探索 n/12 楼计数，FXN-C4 形态待 FXN-BR 脑暴拍板）、完成反馈、空闲 60s 时世界的引导行为（attract 候选/hint 再现/世界「活着」）。**非强制主线**：强制阻断探索的任务设计按本维扣分处理。

| 分段 | 锚点 |
|:---:|------|
| 90-100 | 有可见可选目标 + 进度呈现 + 完成反馈；空闲时世界主动给引导；全部可无视、不阻断自由探索 |
| 70-85 | 至少一条轻目标线可发现可完成，反馈基本；空闲引导弱 |
| 50-65 | 只有隐性动机（POI 分布/收集感）而无显式进度呈现 |
| 30-45 | 纯沙盒零目标：空闲腿 60s 世界无任何响应 |
| 0-25 | 无内容可探索 |

#### F7 可观测完备（10%）

被测：事件白名单接通率（正本归 CC-OBS-DES `docs/spec/cyber-city-observability.md`，落地前以顾问报告 §1.3 v1 为准）、`window.__worldSession.dump()` 可导出且 funnel/counters 齐、`#debug` 面板可用且**只读**、CI 工件（`session-dump-*.json` / `function-smoke.json`）接通。

| 分段 | 锚点 |
|:---:|------|
| 90-100 | 当轮交付面涉及的白名单族 100% 接通；dump 三通道（`__worldSession` / `#debug` 导出 / dispose 摘要）可用；function-smoke 工件在 CI 出现 |
| 70-85 | 漏斗 7 步事件齐 + dump 可导出；个别 ux/error 族缺；`#debug` 可用 |
| 50-65 | dump 可导出但漏斗缺步，或 `#debug` 缺席 |
| 30-45 | 只有散落 `console.info`，无结构化 dump（**现状段位**——OBS-C1 前恒 ≤45，这就是登记前置的机器表达） |
| 0-25 | 无任何可观测面 |

### 2.3 90 分的合成含义（防凑分）

Σ(维分×权重) ≥90 ⇒ 七维几乎全部 ≥85 且至少四维 ≥90——权重最大单维仅 20%，**不存在「某一维满分掩护短板」的凑分路径**。等价校验：任何一维 ≤70 时，其余六维即使全 95 也只得 ~90.0 边缘值；两维 ≤70 则数学上不可达 90。审计时用此做 sanity check：登记 90+ 但存在 ≤70 维的打分单必须复核算式。

## 3. 打分规程与双评门

### 3.1 双评门（沿视觉 rubric v1.1 合议先例）

- **Pass A（脚本执行观察）**：AL-FXN 亲自执行 S-2 + S-5（真浏览器交互，非静态截图拼贴），以「被试视角观察记录」直接给七维初分；
- **Pass B（锚点量表）**：对同一证据集（录屏 + dump）按 §2.2 锚点文本逐条对号入座打分;
- **合议**：两 Pass 总分分歧 >10 触发逐维合议，**以脚本优先铁律仲裁**（对「系统在但脚本动线内遇不到/感知不到」的项下修）；≤10 取两 Pass 逐维合议均值或直接采 Pass B；
- **实现方自评仅供参考，永不登记**（禁止清单 §8 第 1 条）。

### 3.2 取证环境（复现协议）

1. 对象 = 生产 `/` 或 `pnpm build && pnpm preview` 产物（**不测 dev server**，与 e2e/human-gate 口径一致）；桌面 Chrome；无 URL 参数（专项腿除外）；**清存储**（首访者口径）；
2. 全程录屏；每腿结束执行 `JSON.stringify(window.__worldSession.dump())` 落盘（命名 `session-dump-<s2|s5-腿名>-<yyyymmdd>.json`）；
3. 录屏/截图归档 `docs/spec/assets/`（命名含日期与腿别，human-gate §2.0 三件套纪律同构）；
4. **逐维引用 ≥1 条 dump 事件（seq/t）+ ≥1 段录屏时间码**；三问回答原文入报告；
5. CI SwiftShader 环境下的**时长/帧率读数不得用于任何计时类判定**（下界参考 only）；功能维的存在性/顺序性断言不受此限。

### 6.3 登记有效性校验（缺一登记无效）

1. `dimensions[*].weight` 合计 = 1，且与本文件 §2.1（或 §5）一致；`score` = Σ(维分×权重) 取整，允许 ±1 归整差；
2. 每维 `evidence` 非空且含 dump 引用 + 时间码（perf 的 P4 可只引 CI run）；
3. `subject` 含可复现 commit；`scripts` 版本与执行轮次一致；`legsSkipped` 与在途批次事实相符；
4. 同 commit 回归面不塌：e2e 52/52 + function-smoke 无退化 + LHCI 不降（**必要条件非充分条件**）;
5. `scoredBy` = 独立审计（AL-FXN）；出现实现方署名即无效。

## 7. 与 score-loop / e2e 的关系

**综合分五维权重不动**（跨轮可比性优先）：LHCI `/` 25% · LHCI `/home/` 15% · e2e 20% · 视觉 rubric 25% · smoke3d 15%（`scripts/score-loop.mjs` WEIGHTS 单源镜像）。功能/性能分**不折算**进五维，是与综合分**并列**的北极星维度（北极星四数：视觉 98 · 功能 90 · 性能 85 · 综合 98）。
